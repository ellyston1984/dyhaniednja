# Дыхание дня

**Дыхание дня** — спокойный и красивый трекер привычек с astrologией, отслеживанием менструального цикла и родительским режимом.

Приложение полностью offline, с возможностью максимального минимализма и полным отключением любых дополнительных функций.

Часть экосистемы [Дыхание](https://dyhanie.su)

---

## Особенности

### Основные
- Создание привычек с цветом, категорией, днями недели и целью (сколько раз в день)
- Отметка выполнения (включая прошлые дни и частичное выполнение)
- Статистика, серии (строгий / мягкий режим)
- Тёмная тема по умолчанию + светлая + акцентный цвет + монохромный режим
- Полностью offline

### Астрология и эзотерика (можно полностью отключить)
- Фазы Луны
- Управитель дня
- Персональная энергия
- Аффирмации и советы дня
- Недельный лунный обзор

### Женские функции (можно полностью отключить)
- Отслеживание менструального цикла
- Прогноз следующих месячных и фертильного окна
- Режим беременности (заглушка)
- Привычки ребёнка (родительский режим)

### Дополнительно
- Умные подсказки на основе вашей истории
- Поддержка смены языка (ru / en)
- Заглушки для будущих функций (виджеты, уведомления, Health, голосовой ввод и др.)

## Технологии

- **Flutter**
- **Riverpod** — state management
- **Hive / Isar** — локальное хранилище
- Полностью offline-first архитектура
